# Customer logos

Save customer logos here, named after the customer (PNG, JPG, SVG, GIF or WebP, up to 2 MB):

- `contoso.png` is used automatically for "Contoso" or "Contoso Retail"
- `fabrikam.svg` is used for "Fabrikam"

You can also give `create_roi_dashboard` a file path or an https:// URL, or use the
**Upload customer logo** button on the dashboard itself.

Only keep logos here that you're allowed to use in client materials.
