# PowerPoint templates

Save widescreen (13.33 x 7.5 in) `.pptx` or `.potx` templates here, then ask for a deck with
`template="<name>"` (for example, `template="shenuka"` finds `shenuka-brand.pptx`).
You can also pass a full file path.

The deck uses the template's slide masters, backgrounds and title slide layout, and takes its main
colours from the theme (Dark 2 and Accent 1). Slides already in the template are not included.
